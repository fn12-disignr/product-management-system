# Product Management System

A responsive Product Management System built using HTML, CSS, and JavaScript.

## Overview
This project helps users manage products efficiently by providing functionality to add, update, delete, search, and display product information.

## Features
- Add new products
- Update existing products
- Delete products
- Search for products
- Responsive and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- test.html → Main HTML file
- test.css → Styling file
- test.js → JavaScript logic

## How to Run
1. Download or clone the repository
2. Open `test.html` in any browser
3. Start managing products
